# samples

Sample applications for IDEN.

| | |
|---|---|
| [`playground/`](playground/) | A Next.js OpenID Connect client for trying sign-in, step-up and biometric `acr_values` |
| [`door-panel/`](door-panel/) | A Next.js panel of doors that shows access control: roles and groups decide who opens what, live, with face step-up and single sign-out |
| [`engine-lab/`](engine-lab/) | A Next.js app for trying the biometric engine directly: capture, liveness and matching |
